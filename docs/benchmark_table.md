## Reading this table

- **Pearson r / Spearman ρ**: correlation between the model's predicted score and the
  labeled score. Closer to 1.0 is better. Spearman cares about rank order only; Pearson
  also cares about the linear relationship.
- **MAE**: mean absolute error between predicted and labeled score, in points (0-100 scale).
- **Rationale quality**: a stronger model (Claude) grades the *explanation*, not just the
  number, 1-5, so a model can't get credit for a right-for-the-wrong-reason score.
- **Latency**: wall-clock seconds per request, single request, no batching. This is where
  a small fine-tuned model is expected to win even if quality is roughly tied with a
  larger/prompted base model.

## Known limitations

- Labels are synthetic (Claude-generated), not verified recruiter judgments -- see
  [`../README.md`](../README.md#dataset--labeling-honesty) for why, and what that does and
  doesn't tell you about real-world performance.
- Small eval set (10% of an already-small dataset). Confidence intervals on the
  correlation numbers are wide; treat deltas smaller than a few points as noise.
